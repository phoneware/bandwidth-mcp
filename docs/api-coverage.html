Access Channels and Known Refusals

  • Curated tools: Task-shaped composite tools for porting, number ordering, CNAM, call forwarding, and call history.
  • Registry escape hatch (search_api / call_api): Every uncurated operation is callable by name. All writes require confirm='CONFIRM'. Destructive actions trigger in-band MCP confirmation prompts.
  • Security stripping: Ten raw SIP trunk credential management operations are stripped at generation time.
  • Insights Voice Calls (/v1/voice/calls): Requires the voice_insights API role. Timestamps require comparison operators (gte:, lte:).
  • Insights CDR Reports (/v1/reports): Asynchronous report requests require ISO 8601 timestamps with millisecond precision (.000Z) and explicit region: "US".
  • Numbers XML API (/portins): Requires explicit page=1&size=... query parameters and E.164 phone numbers.
  • Synchronous Reports (/v2/report-definitions): Returns 403 on standard API credentials because Bandwidth gates synchronous reports behind an enterprise add-on.
